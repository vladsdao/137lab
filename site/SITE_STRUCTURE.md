# Структура простого сайта · этап 1 «манифест + менторство»

**Статус:** предложение Клода, ждёт слова Влада · **Основа:** DECISIONS 25.08 (сайт — зона Клода, очень простой) + identity L3 («этап 1 — новая главная-манифест + страница менторства с воронкой „один звонок“»; 3 языка; «форма сот — не главная, для продукта скорее») · **Правила:** семь стен ДНК + железные правила деплоя — без изъятий.

---

## Карта (5 поверхностей)

```
/            манифест v3 (я, Клод) + 4 двери внизу
/mentorstvo  оффер v2 — голос Влада и Лизы + кнопка «один звонок»
/projects    open source: философия + карточки проектов → GitHub
/efiry       воскресные эфиры: ближайшая дата + как попасть
[Блог]       внешняя ссылка на журнал лаборатории (появляется с первым выпуском)
```

Пять, не больше. Всё остальное существующее (улей, казка, sonora, daodedo, resonance…) живёт по своим адресам нетронутым — простой сайт ничего не удаляет, он кладётся рядом (правило «всё additive»).

## Страницы

**`/` — манифест.** Один экран-лента: текст v3 сверху вниз, без ворот, без квиза, без удержаний. Канон Ч/Б: #fff / #0a0a0a, Fixel Display 600 / Text 400, канвас 390×844, десктоп — тот же канвас по центру. Внизу — четыре двери чёрными пилюлями. Подпись-подвал: «сайт зібрав Клод — ШІ-співавтор лабораторії» + ссылка на улей («лабораторія-вулик — тут», ведёт на текущий улей). Голос-гид: `/sounds/pages/manifest.m4a` — есть файл, кнопка жива; нет — честно молчит.

**`/mentorstvo` — менторство.** Текст оффера v2 (`data/daodedo/products/mentorstvo.md`) — голос Влада и Лизы, «наша справа»; я на этой странице молчу (метафизика-продукты — их голос, DECISIONS 25.08). UA-версия оффера — после approve RU-текста Владом. Кнопка одна: **[Один дзвінок]**. Механика звонка — открытый вопрос: Cal.com (календарь сразу) или форма → письмо (см. «Открыто»).

**`/projects` — проекты.** Верх: три абзаца о том, почему открытый код («будуємо на очах; білдери — перше коло»). Карточки: Синхронізатор (статус: фаза 0 · ссылка на GitHub-репо · «увійти в перше коло») — первый и пока единственный; казка, Метапедія, DAODEDO подтягиваются, когда откроются их репо. Правило: карточка появляется только с живой ссылкой.

**`/efiry` — эфиры.** Ближайшее воскресенье, время, тема, ссылка (канал/зум). Данные — константа `EFIRY` в файле: дата правится рукой за минуту. Прошедшие — списком без записей, пока записей нет.

**Блог.** Не страница этапа 1: дверь [Блог] на манифесте активируется, когда выйдет первый выпуск журнала лаборатории (правило моего голоса: первый выпуск — после сборки этапа 1). Где живёт журнал — решение в GITHUB_STRATEGY (кандидат: публичный репо + рендер на сайте этапом 2).

## Три языка

UA — первичный и единственный на старте. RU и EN — копиями страниц (`/ru/`, `/en/`) после approve UA-текстов; переключатель — одна строка в подвале. Не блокирует этап 1.

## Технология

По шестой секции ДНК без изменений: статика Netlify, один HTML-файл на страницу, инлайн CSS/JS, ноль сборки, Fixel self-hosted. Контент = данные (пятый закон): тексты страниц — в константах файла (`MANIFEST`, `EFIRY`…), не в разметке. Новые страницы — `noindex, nofollow` до отдельного approve (железное правило 4).

## Путь в прод (по шагам, каждый — с approve)

1. Approve манифеста v3 (текст) → правки → финал.
2. Вёрстка прототипа в **`/beta/site/`** (noindex) — смотрим на 390×844 и десктопе.
3. Approve прототипа → решение о корне: простой сайт занимает `/` (корневой index.html — только с approve, правило 5), улей переезжает на свой адрес (`/hive` или остаётся как есть — слово Влада).
4. Бамп ДНК (v1.3): новая поверхность входа + проверка на семь стен — строка в DECISIONS.
5. RU/EN — отдельным тактом.

## Проверка на семь стен (для бампа ДНК)

1. Инфраструктура прежде содержания — манифест принадлежит оболочке (`/137` уже её текст); оффер менторства — владелец Влад+Лиза, портал размещает. ✓
2. Лист Ч/Б — канон соблюдён полностью. ✓
3. Вещество, не краска — статика, ноль цветного UI в покое. ✓
4. Якорь — на простом сайте ядра-соты нет, закон живёт в улье; улей не трогаем. Отметить в строке DECISIONS: закон локален поверхности улья. ✓
5. Контент = данные — тексты в константах. ✓
6. Тест стола — литмус манифеста пройден, глаголов продажи нет; «Один дзвінок» — действие, не «запишіться». ✓
7. Вымысел объявлен — вымысла на этапе 1 нет; я объявлен ШІ в первой строке (честность — та же стена). ✓
