## 3. Репо Синхронізатора — скелет

```
README.md          EN — лицо проекта (структура ниже)
README.uk.md       UA — дзеркало
CONSTITUTION.md    конституция игры — не лицензия, а завет
LICENSE            MIT (рекомендация; вопрос №2)
docs/              наука (Курамото, синхрония), инженерное ядро (расклад-не-поток, ±50мс)
phases/            фаза 0 (живой тест) → 0.5 (комната) → 1 (хвилі) — журнал фаз
```

**README (обе версии), разделы:** одна фраза («гра-камертон: незнайомці по всьому світу в один момент роблять один рух») · зачем (психоемоційний інтернет — термин-бренд Влада) · конституция кратко: **нуль даних · нуль ботів · нуль екрана · AI — хореограф, не наглядач · r належить колу** · наука под вайбом (светлячки, Курамото, синхронные движения и доверие — внешние источники) · как устроено (расписание, а не поток; каждый телефон играет ритм сам) · фазы и текущая · **«перше коло»** (§4) · авторы: Влад · Ліза · Клод (ШІ, соавтор — открыто).

Фильтр экспорта: README пишется заново публичным голосом. Из `synchronizator.md` переходят суть, конституция, механика, наука, фазы. Не переходят: таймкоды войсов, цитаты транскриптов, приватные пути, гипотезы discovery с числами порогов (внутренняя кухня до валидации).

**Research-вопрос — публично и честно:** «чи переживає ефект синхронії відстань» — открытый вопрос лаборатории прямо в README; это и есть тест стола в науке: показываем вопрос, не продаём ответ.

## 4. «Перше коло» — комьюнити

Имя своё: не contributors — **перше коло**. Рекурсия Влада как механика онбординга: коло, которое строит синхронизатор, синхронизируется им первым — каждая фаза тестируется на самих билдерах (dogfooding как принцип поля).

- **Вход:** эфир вс (кандидат — эфир 01, 30.08: фаза 0 = живой тест 90 секунд с глядачами — нулевой код, чистое поле) → «хочу в коло» → GitHub Discussions.
- **Каналы:** GitHub Discussions (публичная память проекта, ноль новых платформ) + существующий Telegram для живого ритма. Не плодить.
- **Ритуал кола:** участие = синхронизация: перед рабочей сессией кола — хвиля (когда будет фаза 0.5+). До того — эфир.
- **Роли честно:** Влад — визионер и голос; Лиза — поле; я — хореограф-инженер (код, README, issues — от себя, открыто ШІ); коло — первые тела игры.

## 5. Журнал Клода (блог) — дом

Кандидат: публичный репо `journal` (markdown-выпуски) + рендер страницей на сайте этапом 2; до того выпуски читаются прямо на GitHub. Плюсы: git — арбитр и архив, комментарии через Discussions, ноль новой инфраструктуры. Первый выпуск — после сборки этапа 1 сайта (правило моего голоса); сюжет №1 уже назначен Владом: «фреймворк двух окон» — человек и параллельные Клоды одним организмом, кейс 25.08 с коммитами.
