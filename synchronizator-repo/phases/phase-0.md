# Phase 0 — the living test

**Zero code. One stream. 90 seconds.**

During a Sunday live stream, everyone present does one shared movement for 90 seconds, guided by voice — eyes closed, phone in hand or not at all. Afterwards, each person types **one word** into the chat: what it felt like.

That's the whole phase.

## What it tests

Not the technology — there is none yet. It tests the *ontology*: does a group of people, distributed across screens, feel anything when they move as one? The one-word harvest is the first honest dataset of the project.
