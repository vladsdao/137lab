# Стільник кімнат

| | |
|---|---|
| **Нода** | стільник кімнат |
| **Для кого** | дорослий, коло друзів |
| **Складність** | L (місяць+) |
| **Статус** | іскра |

## Що це

Кімната друга у вигляді соти. Заходять лише запрошені — ключем-посиланням, без акаунтів і імен. Усередині кімнати люди присутні одночасно: голос, семпли, символи, малюнок, текст. За замовчуванням нічого не зберігається — прямий досвід, запечатане поле. Але будь-хто може «запечатати» момент: запечатане стає медом і лишається у стрічці соти. Історія кімнати — не запис усього, а те, що хтось вирішив лишити.

## Цикл пробудження

1. **Резонанс** — чуєш, що в кімнаті хтось є, ще не бачачи хто.
2. **Критичність** — рішення запечатати момент.
3. **Нова межа** — коло друзів має місце, якого не було.
4. **Вимір** — стрічка меду, яку намотала кімната.

## Перший крок

Одна кімната на двох з голосом і жестом «запечатати» — по суті сота-мембрана плюс профіль-ескіз, які вже існують у /daodedo/.

## Чого НЕ робимо

Акаунтів, імен, лічильників, сповіщень, зберігання за замовчуванням. Власник змісту кімнати — той, хто її відкрив; оболонка дає лише кімнату.
