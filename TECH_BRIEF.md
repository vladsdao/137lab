# TECH_BRIEF · приложение 137lab

**Версия 1.0 · август 2026.** Технический бриф для Claude Code.
Читается вместе с: `137LAB_DNA.md` (законы), `PORTAL_SPEC.md` (жесты, якорь), `CEREMONY_SPEC.md` (структура 6·8·48+1), `SEVEN.md` (имена).
Рабочий текст — русский. Идентификаторы — английские. Интерфейс — украинский.

---

## 1. Что строим, одной страницей

Портал 137lab — статический сайт, у которого есть три уровня глубины.

**Уровень 1 · Улей.** Первый экран. Семь сот: центр и шесть законов. Тап открывает шторку, удержание вводит внутрь. Улей поворачивается на шаг при каждом выезде ноды вперёд.

**Уровень 2 · Нода.** Сота, доведённая до куба. Три грани — три взгляда на одно содержание. Собирается из манифеста, не из вёрстки.

**Уровень 3 · Контейнер.** Запись церемонии плюс следы всех, кто когда-либо был на этой секунде. Ось контейнера — время записи, не календарь. Внутрь пускает место в октаде, наружу выходит только печать.

Всё остальное в этом брифе — то, как эти три уровня собираются из файлов.

## 2. Границы брифа

**Входит:** маршруты, экраны, зоны, состояния, схема данных, идентичность без аккаунтов, хранение видео, серверный контур, фазы работ, критерии готовности, регресс.

## 3. Технологическая рамка

Уже зафиксировано и не пересматривается: vanilla, один самодостаточный HTML на страницу, ноль сборки, инлайн CSS и JS, шрифты Fixel self-hosted, Netlify auto-deploy, push в main только с approve, всё новое живёт в `/beta` под `noindex`.

Новые решения, которые бриф вводит:

| Решение | Что выбрано | Почему |
|---|---|---|
| секреты | клиент **не знает ни одного ключа** | всё серверное — через Netlify-функции, как уже сделано в `kontrakt.js` |
| база | Supabase, доступ только server-side по service-key | RLS не нужен на первом круге, поверхность атаки минимальна |
| видео | приватный бакет Supabase Storage, signed URL на 15 минут | ≤10 минут на ноду, HLS избыточен; миграция на Stream — когда появится вторая нода |
| идентичность | одноразовая ссылка → ключ устройства в `localStorage` | ни почты, ни пароля, ни профиля на сервере |
| присутствие | Supabase Realtime, только фаза 6 | до этого живой слой не нужен |
| состояние | всё в `location.hash` | грань, нода, грань куба, позиция в записи — шарятся ссылкой |

## 5. Экраны

Все размеры — под канвас 390×844. Нижние 88px считаются подрезаемыми: там не сидит ничего критичного.

### 5.1 Улей · `/beta/lab/`

```
┌─────────────────────────────┐
│ 0–72   шапка: 137lab · стан │  логотип слева, состояние справа
├─────────────────────────────┤
│                             │
│ 72–632  канвас улья         │  SVG, ядро жёстко в CX,CY
│         7 сот, поворот      │  кольцо крутится, ядро — нет
│                             │
├─────────────────────────────┤
│ 632–756 линия поля          │  звук: тап зажигает, тап гасит
├─────────────────────────────┤
│ 756–844 подрез              │  пусто всегда
└─────────────────────────────┘
```

Поведение:
- **тап по соте** → шторка снизу, 60% высоты, ядро не двигается;
- **удержание по соте ≥ 1.2 с** → сота выезжает вперёд и разворачивается в куб, улей поворачивается на один шаг по часовой;
- **удержание по ядру** → флип: лицевая (законы) ↔ оборот (содержание);
- **удержание по ядру до прохождения ворот** → порог, заливка чернилами, событие на отпускании;
- свайпа нет нигде.

Поворот: шаг = 60°, длительность 420 мс, easing без пружины. Верхний слот — позиция «актуальне». Шесть шагов = полный оборот.

### 5.2 Шторка соты

Кикер (нота), имя соты, закон одной строкой, второй строкой — техническое имя закона, действие. Закрывается тапом по фону, Esc, свайпом вниз (вертикаль браузером не отбирается). Фокус возвращается на соту-источник.

### 5.3 Куб ноды

Три грани, имён пока нет — подписаны цифрами `1 2 3` или точками. Переключение — тап по грани или горизонтальные стрелки на клавиатуре. Ядро остаётся на месте, куб живёт над ним.

Каждая грань = слот, в который манифест кладёт модули. Пустая грань показывает «порожньо», а не белый экран.

### 5.4 Контейнер · `/beta/room/<id>/`

Главный экран приложения.

```
┌─────────────────────────────┐
│ 0–64    назад · печать      │
├─────────────────────────────┤
│ 64–283  запись 16:9         │  219px при ширине 390
├─────────────────────────────┤
│ 283–355 таймлайн следов     │  56px полоса + 16 отступ
├─────────────────────────────┤
│ 355–475 октада: 8 мест      │  4×2, своё место подсвечено
├─────────────────────────────┤
│ 475–700 текст грани / тиша  │  что говорит призма
├─────────────────────────────┤
│ 700–756 рука: 3 инструмента │  64px цели
├─────────────────────────────┤
│ 756–844 подрез              │
└─────────────────────────────┘
```

**Таймлайн следов** — сердце всего. Не скраббер, а карта плотности: по горизонтали время записи, по вертикали — сколько следов оставлено на этой секунде за всё время существования контейнера. Тап по столбику перематывает туда. Текущая позиция — вертикальная риска.

Когда ты стоишь на 07:12, ты видишь следы всех, кто когда-либо стоял на 07:12. Дата их визита нигде не показывается — она не имеет значения внутри контейнера.

**Рука** — максимум три инструмента, задаются манифестом. Первый круг: отклик (волна), знак (один из семи), слово (до 24 символов).

### 5.5 Консоль ведущего · `/beta/room/<id>/keeper`

Тот же контейнер плюс: состав (кто из 48 внутри сейчас), партитура по времени, таймер, кнопка печати (удержание 3 с). Ведущий видит плотность следов в реальном времени. Ведущий не видит, кто именно оставил след, — только сколько.

### 5.6 Печать · `/seal/<id>/`

Публичная страница. Форма (гексагон с шестью заполненными секторами), число свидетелей, дата, одна строка ведущего. Ни кадра из записи, ни одного следа, ни одного имени. Кнопка одна: «дізнатись, коли відкриється наступний».

### 5.7 Вход · `/beta/join/#<token>`

Открыл ссылку → функция `join` меняет токен на место → в `localStorage` ложится ключ устройства → редирект в комнату. Токен одноразовый и гаснет.

На этом же экране, до входа, три строки, которые должны быть прочитаны:
- вийти можна будь-коли, без пояснень;
- усе, що всередині, лишається всередині;
- вихід забирає твої сліди.

## 6. Состояние и адресация

```
#/                     улей, лицевая
#/back                 улей, оборот
#/node/<id>            куб ноды
#/node/<id>/f1         грань куба
#t=<ms>                позиция в записи (только в комнате)
```

`hashchange` — единственный источник смены состояния. Жест, клавиатура и ссылка меняют хэш; рендер слушает хэш. Никаких параллельных истин — это первый закон, положенный в код.

История не копится: повороты и смены граней идут через `location.replace`.

## 7. Данные

### 7.1 Манифест ноды — `node/<id>/node.json`

```json
{
  "id": "chastota-01",
  "cell": "chastota",
  "law": "vibration",
  "title": "Частота",
  "faces": [
    { "modules": ["player", "timeline", "hand"] },
    { "modules": ["prism.text"] },
    { "modules": ["law.text"] }
  ],
  "container": {
    "media": "chastota-01.mp4",
    "duration_ms": 612000,
    "prisms": 6,
    "seats_per_prism": 8,
    "hand": ["pulse", "sigil", "word"]
  },
  "seal": { "shape": "hex", "line": "" }
}
```

Новая нода — копия каталога и правка манифеста. Движок не трогается. Если для второй ноды пришлось открыть `.js` — движок не получился.

### 7.2 Таблицы Supabase

**`nodes`** — `id` · `title` · `law` · `slot` · `state` (draft/open/sealed) · `media_key` · `duration_ms` · `opened_at` · `sealed_at`

**`seats`** — `id` · `node_id` · `prism_no` (1–6) · `seat_no` (1–8) · `role` (keeper/prism/witness) · `key_hash` · `joined_at` · `left_at`

**`traces`** — `id` · `node_id` · `seat_id` · `t_ms` · `kind` (pulse/sigil/word) · `payload` (≤24 симв.) · `created_at`

**`invites`** — `token_hash` · `node_id` · `prism_no` · `used_at` · `expires_at`

**`seals`** — `node_id` · `shape` · `witnesses` · `line` · `sealed_at`

Ключевое поле всей системы — `traces.t_ms`. Не `created_at`. Календарное время хранится только для служебных нужд и наружу не выходит никогда.

**Выход стирает следы.** `left_at` проставляется, все `traces` этого места удаляются физически, место освобождается. Это не мягкое удаление.

### 7.3 Серверный контур — Netlify functions

| Функция | Делает |
|---|---|
| `join` | токен → место, отдаёт ключ устройства |
| `trace` | принимает след, режет payload, пишет |
| `traces` | отдаёт агрегат по `t_ms` (гистограмма) и следы окна ±2 с |
| `leave` | помечает выход и стирает следы |
| `seal` | закрывает ноду, пишет печать |
| `media` | выдаёт signed URL на 15 минут, только держателю места |

Клиент не знает ни service-key, ни URL базы. Всё через функции.

## 8. Идентичность

Ни аккаунтов, ни почты, ни пароля.

1. Приглашение — ссылка с токеном, выдаётся ведущим или призмой.
2. Первое открытие — токен обменивается на `seat_id` + случайный ключ, ключ ложится в `localStorage`.
3. Сервер хранит только хэш ключа. Кто это человек — портал не знает и знать не должен.
4. Потеря устройства = потеря места. Восстановление — вручную, ведущим. Это осознанная цена: она же — защита.
5. Имя необязательно. Если человек его дал — оно живёт локально и показывается только ему.

## 9. Видео

Первый круг: файл лежит в приватном бакете, отдаётся по signed URL на 15 минут держателю места. Скачивание не блокируется технически — блокируется договором и тем, что ссылка гаснет. Честно сказать это вслух на входе лучше, чем изображать защиту, которой нет.

Второй круг, когда нод станет больше одной: перенос на Stream с токеном на сессию.

## 11. Фазы

Одна фаза = один заход Claude Code. Следующая не начинается, пока предыдущая не закрыта коммитом.

### Ф0 · Площадка
`/beta/lab/` из копии корня, `X-Robots-Tag` в `_headers` на весь `/beta`, каркас без содержания.
**Готово:** страница открывается, в индексе не появляется, ядро на месте.

### Ф1 · Улей
Семь сот из данных, поворот на шаг, флип ядра, тап и удержание, линия поля молчит по умолчанию.
**Готово:** имена сот меняются правкой одной таблицы; ядро не сдвигается ни на пиксель ни при повороте, ни при флипе.

### Ф2 · Движок ноды
Манифест, слоты, три безымянные грани, монтаж и размонтаж модулей.
**Готово:** вторая нода собрана копированием каталога, без единой правки `.js`.

### Ф3 · Контейнер локально
Плеер, таймлайн, рука, следы в `localStorage`. Сервера нет.
**Готово:** след встаёт на `t_ms`; перезагрузка страницы его не теряет; перемотка по столбику работает.

### Ф4 · Сервер
Supabase, пять функций, приглашения, места, синхронизация следов.
**Готово:** два устройства видят следы друг друга на одной секунде; ни один ключ не виден в исходнике страницы.

### Ф5 · Ведущий и печать
Консоль, партитура, удержание для печати, публичная `/seal/<id>/`.
**Готово:** запечатанная нода больше не отдаёт `media`; печать открывается без ключа и не содержит ничего изнутри.

### Ф6 · Живой слой
Realtime presence, счётчик «скільки зараз на цій хвилині», синхрон при совпадении.
**Готово:** двое на одной секунде видят друг друга; обрыв сети даёт грацию 5 с.

### Ф7 · Промоушен
Копия в корень, снятие noindex, логотип, регресс целиком, approve Влада.

## 13. Регресс-минимум перед каждым коммитом

1. Ядро не двигается: между стадиями, при повороте, при флипе, при открытой шторке.
2. Ни одного цвета в покое. Красное — только отклик на касание.
3. Тач-цели ≥ 44px на 390×844.
4. Нижние 88px пусты.
5. Канвас не скроллится; фокус после шторки возвращается на источник.
6. Клавиатурный проход по всем сотам, граням и инструментам.
7. `prefers-reduced-motion` — поворот без анимации.
8. В исходнике страницы нет ни одного ключа.
9. Запечатанная нода не отдаёт медиа никому.
10. Выход стирает следы: проверяется запросом к базе, а не на глаз.
11. Telegram in-app: открыть, повернуть кольцо, открыть ноду, оставить след.

## 15. Открытые вопросы — блокируют старт

1. **48 включает шестерых или сверх них?** От этого зависит `seats`. Бриф написан по чтению 6 + 42 = 48.
2. **Имена сот:** набор A (ФОКУС · ЧАСТОТА · ФРАКТАЛ · СПЕКТР · ЦИКЛ · СИНТЕЗ · ЕФЕКТ) или B. Меняется одной строкой в `cells.json`, но до Ф1 нужен ответ.
3. **Кто держит вторую ось** — имя человека, к которому можно прийти мимо центра.
4. **Что происходит с октадой, если призма выпала.**
5. **Кто снимает и монтирует запись** — это не портал и не Claude Code.
