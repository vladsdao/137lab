# CLAUDE.md · 137LAB — ОБОЛОЧКА ЛАБОРАТОРИИ

**137lab = лабораторія дослідження свідомості.** Этот репозиторий — портал: оболочка, в которой живут продукты лаборатории. Любая модель, входящая сюда, начинает отсюда.

Тело проекта — **архитектура, дизайн, смыслы и философия портала**. Содержание продуктов (механика DAODEDO, главы казки, методика нейропрактик) принадлежит их проектам; портал берёт у них имя и место на карте. Мозг (память, голоса, worldview, исходники казки) — приватное репо `vladsdao/consciousness-system`.

## Старт каждой сессии

Прочитай шапку `137LAB_DNA.md` — номер версии, затем хвост `DECISIONS.md` — последние решения, затем `PROJECTS_INDEX.md` — что где живёт. Раздел 0 ДНК — семь несущих стен: неизменяемы, проверяй каждое решение на конфликт. Только после этого работай.

## Протокол обновления базы — четыре глагола

Изменил суть → бампни версию ДНК (v1.x) → допиши строку в `DECISIONS.md` → закоммить. Одно решение — одна строка. DECISIONS — append-only: строки не редактируются и не удаляются никогда. ДНК правится только вместе со строкой в DECISIONS — правка без строки не существует. При расхождении поверхностей побеждает репозиторий: git-история — арбитр. Знания чат-проекта — зеркало: обновляются вручную при бампе версии.
