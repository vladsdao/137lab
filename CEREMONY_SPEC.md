# CEREMONY_SPEC · структура церемонии 6·8·48+1

**v0.1 · 2026-08-14 · каркас.** Собран из `TECH_BRIEF.md` v1.0, чтобы бриф не ссылался в пустоту.
Содержание самой церемонии (что происходит, тексты, партитура) — пишет Влад; здесь только несущая структура, которую держит код. Рабочий текст — русский, интерфейс — украинский.

---

## 1. Формула

**6 · 8 · 48 + 1**

- **6 призм** — по одной на грань улья (`SEVEN.md`).
- **8 мест в октаде** — каждая призма держит октаду из восьми мест; призма сама занимает одно из них.
- **48 всего** = 6 призм + 42 свидетеля (чтение брифа §15.1 — ⚠ требует подтверждения Влада).
- **+1 ведущий** (keeper) — сверх сорока восьми, держит консоль и печать.

## 2. Роли

| Роль | `seats.role` | Что может |
|---|---|---|
| Ведущий | `keeper` | консоль `/beta/room/<id>/keeper`: состав, партитура, таймер, печать (удержание 3 с). Видит плотность следов, не видит — кто именно |
| Призма | `prism` | держит октаду, выдаёт приглашения в неё |
| Свидетель | `witness` | место в октаде, запись, следы |

## 3. Порог входа

Вход только по одноразовой ссылке-приглашению (`/beta/join/#<token>`). До входа читаются три строки:

- вийти можна будь-коли, без пояснень;
- усе, що всередині, лишається всередині;
- вихід забирає твої сліди.

Ни аккаунтов, ни почты, ни имени. Ключ устройства в `localStorage`; сервер знает только хэш. Потеря устройства = потеря места; восстановление — вручную, ведущим.

## 4. Время

Ось контейнера — **время записи** (`t_ms`), не календарь. Следы всех, кто когда-либо стоял на этой секунде, живут на ней вместе; дата визита наружу не выходит никогда.

## 5. Рука — три инструмента

| Инструмент | `kind` | Что это |
|---|---|---|
| отклик | `pulse` | волна |
| знак | `sigil` | один из семи (`SEVEN.md`); начертания не решены |
| слово | `word` | до 24 символов |

## 6. Выход

Выход стирает следы **физически** — не мягкое удаление. Место освобождается.

## 7. Печать

Единственная публичная поверхность (`/seal/<id>/`): форма (гексагон, шесть заполненных секторов — шесть призм), число свидетелей, дата, одна строка ведущего. Ни кадра, ни следа, ни имени. Запечатанная нода не отдаёт медиа никому.
