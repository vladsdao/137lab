# PORTAL_SPEC · спецификация оболочки 137lab

Версия 0.2 · август 2026. Живой документ. Правится вместе со строкой в DECISIONS.
Код и идентификаторы — английские, тексты интерфейса — UA, комментарии в коде — как в репозитории.

---

## 1. Модель: face grid

Улей — плоскость граней в целочисленной сетке. Гость всегда стоит на одной грани; жест перемещает его на соседнюю по одной оси.

```js
// координата грани: [x, y]
// title — человеческое имя грани; sign — природа полюса как знак (термин живёт на грани Мета)
const FACES = {
  'lab'  : { at:[ 0, 0], title:'Лабораторія',   sign:null, material:'paper' },
  'vlad' : { at:[ 1, 0], title:'Простір Влада', sign:'→',  material:'…'     },
  'liza' : { at:[-1, 0], title:'Простір Лізи',  sign:'∿',  material:'…'     },
  'meta' : { at:[ 0, 1], title:'Мета',          sign:null, material:'…'     },
  'form' : { at:[ 0,-1], title:'Форма',         sign:null, material:'…'     },
};
```

Правила:

- **Одна ось за жест.** Диагональ игнорируется: побеждает ось с бо́льшим смещением; если разница меньше 12° — жест не засчитан.
- **Только соседи.** С грани `vlad` нельзя попасть на `meta` одним жестом — сперва возврат в `lab`. Мир не рвётся.
- **Якорь.** Ядро рисуется в `CX, CY` всегда. Анимация смены грани двигает соты и вещество, ядро — максимум пульсирует.
- **Логотип = дом.** Клик по логотипу с любой грани и любой страницы возвращает на `lab`.

## 2. Адресация и состояние

| Что | Где живёт | Зачем |
|---|---|---|
| текущая грань | `location.hash` — `#/vlad`, `#/meta` | грань шарится ссылкой |
| прямой вход в улей | `#hive` (легаси, сохраняем) | лого со страниц |
| прохождение ворот | `localStorage: 137school-onboarded` | второй раз без входа |
| сброс | `?reset` | отладка |

`hashchange` — единственный источник смены грани: жест, клавиатура и ссылка меняют хэш, рендер слушает хэш. Никаких параллельных состояний.

## 3. Схема данных

Контент = данные. Ни одной строки текста в разметке.

```js
// нода = сота на грани
{
  id:      'biznes',            // латиницей, = slug страницы
  face:    'lab',               // грань
  slot:    0,                   // 0..5 по часовой с верхней соты
  label:   ['5Д БІЗНЕС'],       // на соте, до двух строк
  full:    '5Д Бізнес',         // в шторке
  desc:    '…',                 // одна-две фразы сути
  href:    '/biznes',           // или null
  act:     'Дізнатись більше',  // подпись действия
  status:  null,                // 'скоро' | 'записується' | null
  owner:   '137lab',            // проект-владелец содержания
  muted:   false,               // нода ещё не живая
  room:    false,               // чужая комната: точка инь-ян на стороне другого полюса
  pair:    false                // сота-мембрана: открывается только вдвоём
}
```

Пустая нода не открывается — защита в `openSheet`. Драфт-тексты помечаются комментарием «ДРАФТ — Влад переписує».

## 4. Жесты и доступность

| Ввод | Действие |
|---|---|
| swipe ≥ 48px, угол < 30° к оси | смена грани |
| tap по соте | шторка |
| tap по соте в звуковом режиме | пэд: звук + волна |
| Tab / Enter / Space | фокус по сотам, открытие |
| ← → ↑ ↓ | смена грани с клавиатуры |
| Esc | закрыть шторку |

Обязательное:

- тач-цели ≥ 44px; `touch-action: manipulation`; выделение текста выключено;
- `prefers-reduced-motion` — смена грани без анимации, волны и слова мгновенные;
- канвас не скроллится никогда: `overflow: clip` + страховка на `scroll`;
- фокус после закрытия шторки возвращается на источник, `preventScroll: true`;
- каждая грань объявляется скринридеру через `aria-label` контейнера улья.

Зона риска: in-app браузеры Telegram и Instagram подрезают нижний край. Ничего критичного (подсказка жеста, лента, кнопки) не сидит впритык к низу.

## 5. Порог

Жест входа: hold ≥ 4 с. Заливка соты чернилами снизу — функция времени удержания. Событие наступает на `pointerup`, не на нажатии. Уход пальца за пределы соты отменяет жест. Клавиатурный эквивалент — удержание Enter. `prefers-reduced-motion` — заливка без анимации, порог 2 с.

## 6. Сота-мембрана

Открывается только при двух присутствиях в комнате. Каждый участник получает свой текст и не видит чужой. Выход одного сворачивает мембрану у обоих, с грацией 5 секунд на обрыв сети. На сервере не хранится ничего, кроме факта присутствия — закон запечатанного поля. След остаётся локально у каждого.

## 7. Вещество граней

Грань отличается материалом, не краской.

| Слой | Что можно менять | Что нельзя |
|---|---|---|
| фон | плотность и штрих решётки, зерно, ритм пульса | цветную заливку, градиенты-бренд |
| сота | форму подписи, кегль, толщину штриха | новый шрифт, вес 700 |
| движение | скорость и характер выхода сот | «оживление» без причины |
| звук | строй пэдов, тембр, темп | музыку без действия гостя |
| цвет | только отклик на касание (нота → цвет) | цвет в покое |

Мейн-грань `lab` — эталон: чистый лист, ничего лишнего. Остальные грани доказывают своё вещество на mobile-viewport, прежде чем поедут в корень.

Стороны различаются веществом решётки: **Простір Лізи (∿)** — плотная ровная решётка, медленный пульс; **Простір Влада (→)** — разреженная подвижная решётка, быстрый пульс. Цвета нет ни там, ни там.

## 8. Словарь событий портала

Тонкая шина: одно место, куда стучат все органы (улей, шторка, звук, лента, будущие комнаты).

| Событие | Смысл | Излучает | Принимают |
|---|---|---|---|
| `face.enter` / `face.leave` | смена грани (`{id, at, source}`) | роутер хэша | улей, фон, звук, аналитика |
| `gate.pass` | ворота пройдены | ворота | улей, локальное хранилище |
| `node.open` / `node.close` | шторка ноды | улей | шторка, фон |
| `node.activate` | переход на страницу ноды | шторка | навигация |
| `pad.hit` | касание пэда (`{id, note, color}`) | улей, лозенджи | звук, волны, слова |
| `wave.spawn` | волна отклика (`{x, y, color}`) | любой орган | слой волн |
| `guide.play` / `guide.stop` | голос-гид страницы | кнопка «голос» | аудио |
| `feed.push` | отзыв отправлен | форма | Netlify-функция |
| `room.presence` / `room.sync` | присутствие и синхрон в живой комнате | Supabase | комната |
| `hold.begin` / `hold.release` | удержание порога началось / отпущено | порог | заливка, звук |
| `breath.tick` | дыхание поля (5–6 циклов/мин) | звук | фон, заливка |
| `membrane.open` / `membrane.collapse` | мембрана открылась вдвоём / свернулась | Supabase | комната, шторка |
| `window.open` | ритуальное окно наступило | расписание | улей, звук |

Правило: орган не знает о других органах — только о шине. Новый девайс, стрим или комната подключаются как подписчик, без переписывания улья.

## 9. Правила изменения

1. Правка канона (токены, вещество, модель граней) невозможна без строки в DECISIONS.
2. Новая грань или нода сначала живёт в `/beta` под `noindex`, затем промоушен в корень тем же рецептом (копия + title + снятие noindex + логотип) и только с approve.
3. Всё additive: без удалений, массовых перезаписей и `git push --force` без отдельного подтверждения.
4. Регресс-минимум перед промоушеном: ворота (двойной тап не открывает шторку ядра), якорь не сдвигается между стадиями, канвас не уезжает после фокуса, аудио 404 не ломает интерфейс, клавиатурный проход по всем сотам.
